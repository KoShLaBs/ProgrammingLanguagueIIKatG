## ✅ Objetivo

Desarrollar un programa en lenguaje de programación phyton que evidencia la aplicabilidad de herencia, reutilización de código, polimorfismo, modularidad, manejo de archivos. Este debe mostrar un menú con las siguientes opciones:

1. Registrar Developer.
2. Registrar QA.
3. Mostrar lista de empleados.
4. Modificar datos de un empleado.
5. Eliminar un empleado
6. Salir.

El programa debe tener validaciones, también debe usar Get y Set , y POO todos sus pilares

## ✅ Objetivo

Desarrollar un proyecto en Python donde se evidencia el uso de herencia, polimorfismo..

Una empresa desea desarrollar un sistema en Python para registrar la información de dos empleados.
Para ello, se debe crear una clase base llamada Empleado, que contenga los datos generales de cada trabajador, como: nombre, edad e identificación.
Y dos clases hijas con dos atributos
